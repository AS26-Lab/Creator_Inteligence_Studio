# Creator Language Analysis / Narrative Profile

## Scope

This phase analyzes local source material selected by creator to describe how the creator speaks and structures content.

It uses only local inputs:

- transcriptions and transcript segments;
- subtitles and subtitle segments;
- approved Creator Memory examples;
- titles, captions, copies and manual text;
- selected video segments;
- existing acoustic metadata.

## What it does

- builds explicit corpora by creator;
- tokenizes and segments Spanish text deterministically;
- measures vocabulary, sentence length, filler words, discourse markers, rhythm and pauses;
- detects opening, development, explanation, humor and closing patterns;
- compares styles by platform and content type when samples are comparable;
- versions narrative profiles and evidence-backed candidates for Creator Memory.

## What it does not do

- no script generation;
- no LLM;
- no ML;
- no embeddings;
- no external APIs;
- no automatic profile mutation;
- no automatic promotion to Creator Memory.

## Core rule

The analysis describes observed patterns, not intentions or inner state. It may propose candidates for review, but a human must approve anything that should move into Creator Memory.

## Outputs

- analysis runs;
- language metrics;
- narrative patterns;
- retrieval results;
- profile snapshots;
- reviewable candidates;
- JSON, TXT and CSV exports.

## Privacy

- all processing stays local;
- creators remain isolated;
- exports are explicit;
- private text is minimized;
- no full-corpus logs by default.
